# Proyecto: Semáforo con Wokwi

## Descripción
Este proyecto consiste en simular el funcionamiento de un semáforo utilizando una placa ESP32 y tres luces LED: roja, amarilla y verde. La simulación se realiza en Wokwi.

## Funcionamiento
- La luz roja se enciende para indicar detenerse.
- La luz verde se enciende para indicar avanzar.
- La luz amarilla se enciende para indicar precaución antes del cambio de luz.

Las luces se encienden de manera secuencial, respetando los tiempos programados en el código.

## Materiales utilizados
- Placa ESP32.
- LED rojo.
- LED amarillo.
- LED verde.
- Resistencias.
- Cables de conexión.
- Simulador Wokwi.

## Objetivo
Comprender cómo controlar salidas digitales mediante programación y representar el funcionamiento básico de un semáforo.
